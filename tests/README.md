# Проверка скачивания

Установка: `npm ci` (Node.js). Для сетевой проверки нужен Python 3 без дополнительных библиотек.

- `npm test` — исполняет настоящий app.js в jsdom и проверяет каждую кнопку карточек, всех галерей и каждую строку файла. Проверяет точный URL, имя архива, состояние недоступности и красную рамку, открытие правильной галереи. Для каждой строки сверяет путь, размер и CRC файла с оглавлением ZIP.
- `npm run test:links` — без аккаунта Google проверяет все архивы по сети: HTTP Range, сигнатуру ZIP, Content-Disposition с правильным именем и оглавление ZIP. Загружает только заголовки и оглавления, а не гигабайты моделей.
- `npm run test:all` — последовательно выполняет обе проверки.

`download-audit.json` содержит результат для каждого элемента, включая заблокированные кнопки. Недоступные ссылки считаются корректно обработанными только при отсутствии href, aria-disabled=true и классе красной рамки. Это не означает, что эти архивы доступны.

`source-catalog.json` — исходный список локальных файлов; `download-contract.json` — ожидаемые назначения; `archive-index.json` — проверенное оглавление опубликованных ZIP. При добавлении файлов обновите эти данные вместе с catalog.js. Сетевая проверка намеренно не меняет назначения кнопок: замена ZIP обнаруживается как несовпадение.

Тесты DOM не являются визуальной проверкой браузера. Проверяется структура и обработчики реального сайта, без захвата экрана или управления пользовательским браузером.

# Проверка библиотек бекеров

`npm ci`, затем `npm test`.

Тесты проверяют расшифровку правильной ссылкой, подмену тира, неверные ключи, испорченный каталог, сетевые ошибки и закрытую начальную страницу.

В локальном проекте дополнительно проверяется каждая кнопка Core, Full и Complete: галерея, пакет, строка файла, общий архив, красная рамка недоступной ссылки. Проверяется не только нужный файл внутри ZIP, но и весь ZIP: он не должен содержать ресурсов старшего тира.

Приватные данные берутся из соседней папки `Служебное/Тиры` или из `CT2_PRIVATE_DIR`. В чистом клоне без этой папки реальный каталог не проверяется; тест явно отмечен skipped. Ключи не нужны для общих тестов и никогда не хранятся в Git.

`npm run test:links` повторно проверяет Google Drive через HTTP Range: ZIP-сигнатуру, имя скачиваемого архива и его оглавление. Большие ZIP целиком не скачиваются. Отчёты сохраняются только в приватную папку.

Кнопки с пока не загруженными архивами должны быть отключены, с красной рамкой; это не означает, что архив уже доступен. Перед рассылкой нужно загрузить подготовленные ZIP и повторить проверку.

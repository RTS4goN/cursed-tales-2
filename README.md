# Cursed Tales 2

Статический сайт коллекции: персонажи, Chibi и диорама. Галерея и список файлов каждого персонажа, скачивание проверенных ZIP-комплектов STL, рендеров и Chitubox, кнопка скачивания всей коллекции.

## Скачивание

Исходные STL и ZIP не хранятся в репозитории. Недоступные архивы отмечены красной рамкой. Строки файлов скачивают ZIP, содержащий выбранный файл. Пометка «общий ZIP» означает загрузку всей доступной коллекции. Ссылки задаются в `catalog.js`; скачивание выполняется с Google Диска.

Локальная версия хранится отдельно и скачивает подготовленные ZIP с компьютера. Публикуемая версия содержит только сайт и оптимизированные изображения.

## Обновление

После загрузки ZIP на Google Диск заполните файл `Служебное/Ссылки Google Диска.json` в локальной папке проекта: имя ZIP → HTTPS-ссылка скачивания. Запустите `Служебное/Подготовить публикацию.py`, затем отправьте изменения этой папки в GitHub.

Наличие STL проверяется при подготовке каталога. Отсутствующие модели отмечены красным. Проверки скачивания: `npm ci`, затем `npm run test:all`. Подробности в `tests/README.md`.

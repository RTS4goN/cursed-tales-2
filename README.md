# Cursed Tales 2

Статический сайт коллекции: 6 персонажей, 3 Chibi и диорама. Галерея и список файлов каждого персонажа, скачивание отдельных файлов и комплектов STL, рендеров и Chitubox, кнопка скачивания всей коллекции.

## Скачивание

Исходные STL и ZIP не хранятся в репозитории. До загрузки архивов кнопки скачивания неактивны. Ссылки задаются в `catalog.js`; скачивание выполняется с Google Диска.

Локальная версия хранится отдельно и скачивает подготовленные ZIP с компьютера. Публикуемая версия содержит только сайт и оптимизированные изображения.

## Обновление

После загрузки ZIP на Google Диск заполните файл `Служебное/Ссылки Google Диска.json` в локальной папке проекта: имя ZIP → HTTPS-ссылка скачивания. Запустите `Служебное/Подготовить публикацию.py`, затем отправьте изменения этой папки в GitHub.

Наличие STL проверяется при подготовке каталога. Отсутствующие модели отмечены статусом «Файлы пока недоступны».

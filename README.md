# Cursed Tales 2

Библиотека бекеров с тремя наборами: Core, Full и Complete. Вход по отдельной ссылке, без регистрации. Состав наград сверяется с Kickstarter.

Каталоги зашифрованы AES-256-GCM отдельно для каждого набора. Ключ находится в ссылке после `#` и не публикуется в репозитории. Начальная страница без ссылки не выдаёт скачивания. Ссылка переносима: это доступ по ссылке, а не проверка личности бекера.

Google Drive хранит ZIP. Каждый доступный ZIP проверен по составу, размерам и CRC: архив не должен содержать ресурсов старшего тира. Недоступные архивы отмечены красной рамкой. Старые публичные ссылки Google Drive продолжают работать; эта схема не отзывает ранее выданные файлы.

## Обновление

В локальной папке проекта запустите `Служебное/Подготовить публикацию.py`. Ключи, ссылки для рассылки, исходные каталоги и отчёты находятся вне репозитория, в `Служебное/Тиры`. Не публикуйте эту папку.

`npm test` проверяет механизм ссылок, расшифровку и интерфейс. При наличии локального проекта также выполняется проверка каждой кнопки всех трёх наборов. Инструкции — в `tests/README.md`.
